# issue 6860 — 자리차지 표의 앵커 줄

자리차지(`TopAndBottom`, `vertRelTo=PARA`) 표를 앵커한 호스트 문단이 자기 글자를
두 줄 이상 가질 때, 그 줄이 표보다 위에 남는지를 잠근다.

원본 `3067979_[붙임 2] 도로안전시설 설치 및 관리 지침- 조명시설편.hwpx` 88쪽에서
호스트 두 줄이 마지막 표 조각 뒤로 밀려 본문 하단 밖에 그려졌다. 한글 저장
`hp:linesegarray` 는 그 줄을 표보다 위에 적어 두었다.

```text
  문단 1522 (직전)   vertpos = 29132
  문단 1523 줄0     vertpos = 30732   vertsize = 1000   textpos = 0
  문단 1523 줄1     vertpos = 32332   vertsize = 1000   textpos = 56
  ── 표 밴드 (33332 … 74427) ──
  문단 1524 (다음)   vertpos = 74427
```

표는 `vertOffset=1256` 이고 제어 문자가 텍스트 맨 끝이라 앵커 줄은 줄1 이다.

```text
  앵커 줄 기준(정답)  표 상단 32332 + 1256 = 33588  ≥  줄1 끝 33332
  첫 줄 기준(결함)    표 상단 30732 + 1256 = 31988  <   줄1 시작 32332
```

이 fixture 가 잠그는 것은 절대 좌표가 아니라 차례(호스트 두 줄 → 캡션 → 표)와
쪽 귀속(표가 시작하는 쪽, 마지막 조각 뒤 아님)이다.

구역0 최상위 `hp:p` 1,747개 중 `0`(`secPr` 보유) · `1521` · `1522` · `1523` ·
`1524` 만 남기고 `BinData/` 56개를 스텁으로 치환했다. 2,502,806 → 26,868 바이트.
